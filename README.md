# نظام ملاعبنا لحجز الملاعب الرياضية

نظام حجز ملاعب رياضية مبني باستخدام **HTML وCSS وJavaScript وPHP فقط**، بدون إطار عمل أو قاعدة بيانات.

## التشغيل

1. انسخ مجلد `sports-booking` إلى مجلد الخادم المحلي مثل `htdocs` في XAMPP.
2. شغّل Apache.
3. افتح: `http://localhost/sports-booking/index.html`
4. لوحة الإدارة متاحة عبر: `http://localhost/sports-booking/admin.html`

للتشغيل من الطرفية باستخدام PHP:

```bash
cd sports-booking
php -S localhost:8000
```

ثم افتح `http://localhost:8000`.

## ملفات HTML المستقلة

- `index.html`: الصفحة الرئيسية وواجهة الحجز.
- `admin.html`: لوحة الإدارة وتعرض البيانات من `api.php`.
- `how-it-works.html`: شرح خطوات استخدام النظام.
- `contact.html`: صفحة التواصل وإرسال الرسائل.

> يلزم تشغيل الصفحات عبر Apache أو خادم PHP حتى تعمل الحجوزات؛ فتح HTML مباشرة قد يمنع طلبات API.

## المزايا

- واجهة عربية RTL متجاوبة مع الجوال.
- البحث والتصفية حسب نوع الرياضة.
- نموذج حجز مع التحقق من رقم الجوال والتاريخ.
- منع حجز نفس الملعب في نفس الموعد.
- حفظ الحجوزات في `data/bookings.json`.
- لوحة إدارة لعرض الحجوزات وإلغائها.

> ملاحظة: لوحة الإدارة الحالية تجريبية ولا تحتوي على تسجيل دخول. أضف نظام مصادقة قبل استخدامها على خادم إنتاجي.
